# Dataset

## What's in this folder

- **`Grocery_and_Gourmet_Food.txt`** (1.68 MB) — the preprocessed input that ICSRec actually reads. One user per line, space-separated, leading integer is the user ID, the rest are item IDs in chronological order. Generated by `notebooks/1_preprocess_grocery_for_icsrec.ipynb`.

We include this file so a grader (or future user) can skip the preprocessing step entirely. To regenerate it from the raw CSV, run notebook 1.

---

## Source

This dataset is the **Grocery and Gourmet Food** subset of the **Amazon Reviews 2023** corpus, released by the McAuley Lab at UC San Diego (Hou et al., 2024).

- **Hugging Face:** <https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023>
- **File used:** `benchmark/5core/rating_only/Grocery_and_Gourmet_Food.csv`
- **Project page:** <https://amazon-reviews-2023.github.io/>
- **Paper:** Yupeng Hou et al., *Bridging Language and Items for Retrieval and Recommendation*, arXiv:2403.03952, 2024.

The CSV has four columns: `user_id` (string hash), `parent_asin` (item id, string), `rating` (1-5 float), `timestamp` (Unix milliseconds). It is already pre-deduplicated and 5-core filtered by the McAuley Lab.

**Original size:** 3,948,741 interactions, 404,760 users, 132,865 items.

---

## Preprocessing we applied

In `notebooks/1_preprocess_grocery_for_icsrec.ipynb` we:

1. Sort each user's interactions by timestamp (critical for sequential recommendation).
2. Drop any rows with nulls or exact (user, item, timestamp) duplicates.
3. Apply iterative **15-core filtering** (a stricter version of the paper's 5-core, to bring the dataset to a size comparable to the paper's Beauty/Sports/Toys benchmarks). This converges after 14 iterations.
4. Filter to users with at least 3 interactions (needed for train / valid / test leave-one-out splits; redundant with 15-core but kept as a safety check).
5. Remap user and item IDs to consecutive integers starting at 1 (ID 0 is reserved for padding inside the model).
6. Emit the ICSRec format: one user per line, space-separated.
